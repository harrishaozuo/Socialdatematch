# 碰个面 · Melbourne Mates

面向墨尔本华人的个人展示、付费活动陪伴与免费找搭子 App 原型。使用原生 JavaScript、CSS 和 Node.js，无第三方运行依赖。

## 开发与测试

需要 Node.js 22 或更高版本。

```sh
cd /workspace/Socialdatematch
npm test
npm run dev
```

默认端口 3000，可用 `PORT=3001 npm run dev` 覆盖。11 项单元测试覆盖筛选、整数分计价、成年资料校验、最低时长、墨尔本当地日期、可预约日、时段边界和免费活动。

## 第一版产品

- 发现以人物卡片为核心：首页展示昵称、兴趣、区域、年龄、性别与澳元时薪，可筛选、搜索、按价格排序和收藏。
- 个人展示：支持最多 3 张 JPG/PNG/WebP 照片、本机压缩、自我介绍、服务内容、语言、可预约日、时薪和最低时长。可以编辑或暂停上架，所有成年人均可使用。
- 预约：选择活动、日期、时间、小时数和留言，先算总价再提交。校验可预约星期、今天起 60 天范围和午夜前结束；未处理申请不能重复提交。
- 接单与收益：在“我的”主动生成演示询价，体验接受／拒绝、模拟付款和完成活动。只把完成的演示订单计入收入，保留预约时的价格快照。
- 免费搭子：保留活动发布、申请、取消、删除和原有本机活动记录。
- 手机 App 体验：底部导航、响应式个人详情与表单、独立窗口安装配置、图标和离线页面缓存。

## 盈利假设

当前按完成的付费订单抽取 **15%** 平台佣金，**从接单方所得中扣除**，不对预约人叠加收费。A$30 × 2 小时 = A$60，佣金 A$9，接单方预计所得 A$51。餐饮、门票和交通费用另计；支付手续费、税费、退款和真实结算尚未接入。免费搭子不抽佣。

比例需要商业验证，不是正式收费承诺。会员和明确标识的推广位是后续候选收入来源。完整规则与开发路线见 [产品说明](docs/PRODUCT.md)。

产品下一阶段将扩展为活动陪伴、职业交流、有偿求助和兴趣搭子四个业务入口。板块用途、统一导航、30／60 分钟 Coffee Chat 套餐与需求接单流程见 [社区架构方案](docs/COMMUNITY_ARCHITECTURE.md)。该文档是待实施方案，当前原型尚未支持职业套餐或需求广场。

## 查看与安装原型

GitHub 仓库 Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save。部署后使用 Pages 页面提供的网址。若账号方案不支持当前仓库部署，选择其他静态托管服务，无需改动仓库隐私设置。开启 Pages 会使原型通过网络访问。

HTML、模块、图标、manifest 和 service worker 均使用相对路径，支持仓库子路径。服务器显式列出公开资源，不公开环境文件等私有路径。Service worker 只缓存应用代码和图标，使用网络优先策略；不缓存支付响应或额外远端请求。

Android 支持的浏览器可选择“安装应用”或“添加到主屏幕”；iPhone 使用 Safari 分享菜单的“添加到主屏幕”。安装需要 HTTPS（本机开发地址也可用于测试），浏览器支持有所不同。当前交付是网页 App，**还不是 App Store／Google Play 原生安装包**。

## 验证范围与限制

Chromium 已验证手机筛选与收藏、展示照片上传、资料保存与刷新恢复、上架暂停、预约总价、申请与取消、演示接单与收入，以及免费活动发布／申请／取消；已验证 service worker 缓存后的离线打开。仍需真实 iPhone／Android 设备和商店版测试。

资料、照片、收藏和订单保存在当前浏览器 localStorage，不跨设备、不发送给其他用户。示例人物使用插画，未经身份核验，所有订单和收入均为模拟。不要输入身份证件、支付资料、私人住址等敏感信息。清除浏览器数据会删除本机记录。

真实多人上线需要账号、数据库、照片存储、权限控制、可预约时段、双方确认、订单消息、支付与退款、举报拉黑及后台管理。服务限定为成年人在公共场所参加活动，不承诺恋爱关系。生产订单金额与状态必须由后端计算和验证，不能依赖浏览器或演示按钮。商店版还需要原生打包、设备测试和发布账号。
