# 碰个面 · 可交互手机 App 原型

面向墨尔本华人的时间、经验与互助社区，包含活动陪伴、职业交流、有偿求助和兴趣搭子。当前版本 **0.5.0**，手机导航为发现、需求、发布、消息、我的。

## 先体验

- `index.html` 是支持主屏幕安装与离线打开的网页 App，适合通过 HTTPS 网站在手机 Safari / Chrome 打开。
- `demo.html` 是完整的单文件交互导出，HTML 内含所有界面和业务代码，不依赖外部运行资源。适合下载后用允许执行 JavaScript 的浏览器预览；手机文件预览器可能不执行脚本，手机建议访问网页版本。
- 三条推荐体验流程与手机安装方法见 [手机体验说明](docs/TRY_MOBILE.md)。
- 查看 [产品思维导图](docs/product-mindmap.html)：可折叠分支、单独打开或打印；也提供 [图片版](docs/product-mindmap.png)、[PDF 版](docs/product-mindmap.pdf)和便于修改的 [Markdown 版本](docs/PRODUCT_MINDMAP.md)。

示例展示使用真人摄影素材；人物姓名、经历、价格和预置需求都是虚构数据，照片不代表被摄者提供这些服务或通过核验。发布、聊天、订单与评价保存在当前浏览器。付款、收入、对方确认与回复都是明确标注、由用户主动触发的演示，不联系真实用户，不产生资金交易。照片原文件保存在仓库中，来源与许可记录见 [演示照片说明](docs/PHOTO_CREDITS.md)。

## 已实现的交互

- **发现**：紧凑的四个业务入口、真人摄影卡片、人物与价格展示、职业服务与付费需求信息流、关键词搜索和内容筛选。
- **活动陪伴**：人物展示、照片上传、兴趣与区域筛选、时薪预约及取消，保留原有本机数据。
- **华人社区展示**：中文昵称、普通话／粤语与墨尔本生活场景；当前三个摄影示例人物在不同服务板块保持同一昵称和照片。旧版未上架的示例资料保留，用于读取已有本机预约。
- **职业交流**：独立服务详情，支持 A$100／30 分钟、60 分钟等套餐，不把职业套餐绑在人物时薪上。
- **需求**：填写目标、预算、日期、线上／线下及预计时长；申请示例需求，或为自己的需求主动生成演示申请并选择一人。
- **发布**：同一展示可挂多项服务，自行定价、暂停上架；也可发起免费活动或分享经验。
- **消息与订单**：提交申请后进入订单会话，发送留言、主动生成演示回复、确认／拒绝、模拟付款、取消、完成、评价与再约。
- **我的**：个人展示、服务和需求统计、预约入口、核验流程说明与完成接单后的模拟收入；买方支出不计入服务者所得。
- **免费搭子**：发布活动、申请同行、取消和删除。

## 开发与导出

开发及测试使用 Node.js 24 或更高版本。无第三方运行依赖，不需要 npm 安装。

```sh
cd /workspace/Socialdatematch
npm test
npm run export
npm run dev
```

默认端口 3000。如被占用可用 `PORT=3001 npm run dev`。`npm run export` 从当前代码重新生成 `demo.html`，将展示照片一并嵌入，不读取浏览器资料；修改界面、照片或业务代码后重新导出。

`npm test` 在同一进程运行 19 项用例，覆盖整数分计价、30 分钟套餐、时长边界、墨尔本时间、上架资料、需求预算与订单状态。Chromium 已检查职业预约至模拟完成评价、需求申请与选人、多服务上架、消息和刷新恢复、收入归属、存储被禁用的处理，以及单文件载入后离线操作。各主要页面适配 320px 宽度。主网页的 service worker 离线恢复独立检查。

## 网页发布与手机安装

在 GitHub 仓库 Settings → Pages 中选择 Deploy from a branch → `main` → `/(root)` → Save；部署后使用 Pages 设置里提供的实际网址。若账号方案不支持当前仓库部署，选择其他静态托管服务，无需改动仓库隐私设置。

HTML、模块、样式、图标、manifest 和 service worker 使用相对路径，支持仓库子路径。`demo.html` 可单独托管，但安装和缓存支持请使用普通 `index.html` 入口。开发服务器只开放明确列出的资源。

iPhone：Safari 分享 → 添加到主屏幕。Android：支持的浏览器菜单 → 安装应用／添加到主屏幕。安装需要 HTTPS 与受支持浏览器。当前是网页 App，未生成 App Store／Google Play 原生安装包，真实手机设备测试仍需进行。

## 收费模型与后续

付费订单暂按 **15%** 试算佣金，从服务者所得扣除，不向预约者加价。例如 A$100 的订单，佣金 A$15，服务者预计到手 A$85。餐饮、门票、交通另计；手续费、税费、退款及真实结算尚未接入。免费搭子不抽佣。
