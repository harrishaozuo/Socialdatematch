# 碰个面 · Melbourne Mates

面向墨尔本华人的中文活动搭子与付费活动陪伴网站原型。使用原生 JavaScript、CSS 和 Node.js，无第三方运行依赖。

## 开发

需要 Node.js 22 或更高版本。

```sh
cd /workspace/Socialdatematch
npm run dev
```

默认端口 3000，可用 `PORT=3001 npm run dev` 覆盖。`npm test` 验证筛选、预约计价及发布校验。

## 线上原型预览（GitHub Pages）

在仓库的 Settings → Pages 中，选择 Deploy from a branch，分支 `main`，目录 `/(root)`，点击 Save。部署完成后，使用 Pages 页面提供的网址查看原型。若账号方案不支持当前仓库的 Pages 部署，需选择其他静态托管服务；不要为此改动仓库隐私设置。

HTML 使用相对资源路径，支持仓库子路径部署。预览仅展示本机模拟流程，不接收真实支付，也不支持不同用户共享资料。不要填写敏感信息。开启 Pages 会使原型页面可通过网络访问。

## 功能

- 手机和桌面布局，中文内容，墨尔本当地日期，澳元价格。
- 活动类型、区域、收费方式筛选及关键词搜索。
- 活动详情与示例人物介绍。
- 发布活动、费用说明、成年与服务边界确认。
- 1–8 小时模拟预约、留言、重复申请拦截、取消与重新申请。
- 我的预约、我的发布和删除活动。
- 浏览器本机存储；示例资料及模拟流程明确标注。

## 产品规则与后续工作

免费搭子无陪伴费，活动开销提前约定；付费陪伴按服务者时薪计算，其他开销另计。目前无真实付款、平台抽成或多人通信。

真实上线需要数据库、账号体系、服务者可预约时段、双方确认、聊天、支付与退款、举报拉黑、年龄和身份核验、后台管理、隐私政策和维州服务规则审查。推荐订单状态为申请待确认 → 已接受 → 待支付（付费）→ 已预约 → 已完成；取消、拒绝和争议为独立状态。支付需后端计算价格并通过支付平台 webhook 确认，不能信任浏览器价格或客户端状态。

当前用户数据仅存于 localStorage，不跨设备、不共享、不作为真实订单。不要输入敏感信息。示例人物不代表真实用户。
