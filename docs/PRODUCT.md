# 碰个面：产品方向与现有原型

产品方向已扩展为面向墨尔本华人的时间、经验与活动互助社区，包含活动陪伴、职业交流、有偿求助和兴趣搭子四个业务入口。下一阶段的板块、导航、发布方式和收费规则见 [社区架构方案](COMMUNITY_ARCHITECTURE.md)。以下记录现有原型已实现的能力与技术规则；职业服务套餐和需求广场尚未实现。

## 现有原型范围

先从墨尔本 CBD、Carlton、Clayton 的华人用户开始，提供个人展示、按小时预约活动陪伴，以及免费找搭子。服务者可以选择自己想参与的活动、填写介绍、设置澳元时薪和最低预约时长，并随时暂停展示。男女均可展示和预约；展示资料表达个人兴趣及服务范围，不承诺恋爱关系。

第一版以手机为主要使用场景，发现页先展示人物、兴趣、区域和价格，再进入详情及预约。资料和预约保存在当前浏览器，示例资料不代表真实服务者。原型提交申请只演示流程，不通知对方、不产生真实订单或支付。

## 第一阶段盈利假设

付费陪伴的时薪由服务者设定，范围为 A$10–200，最低预约时长为 1–8 小时。拟从完成的付费陪伴订单抽取 15% 平台费，由服务者收入中扣除，不额外向用户加收。平台费率是需要真实测试的商业假设，尚未形成实际收费条款。

例如 A$25/小时 × 2 小时，预约人支付 A$50，平台费 A$7.50，服务者所得 A$42.50。餐饮、门票、交通等活动开销另行约定，原型不代收。价格先转为整数分再计算，平台费四舍五入至分，服务者所得为总价减平台费。

免费搭子不收陪伴费和平台费，活动开销由双方提前约定 AA 或各自支付。商业验证重点为有效预约数、确认率、完成率、复购、获客成本和完成订单后的净收入；完成前的申请数不算收入。示例费率未计支付渠道、退款、税务及运营成本，因此不能视为净利润承诺。

后续可以测试会员与明确标识的推广位，提供真实、可核实的权益。禁止伪造在线状态、收入、评价、身份认证或用户数量；推广不得伪装成自然推荐。

## 网站与 App

当前交付是可安装到主屏幕的移动网页原型，适合分享链接、低成本验证预约需求。真实 iOS/Android App 是后续独立交付，仍需打包、设备测试、应用商店发布和相应后端支持。原型的本机保存不支持不同用户之间交流，也不保证跨设备恢复。

## 当前业务规则

- 上架资料：昵称 1–24 字，年龄整数 18–80，性别为女生、男生或其他，区域 1–40 字，个人介绍 10–300 字。
- 服务类别：1–6 个不同的活动服务，每项 1–20 字；由展示页选择并描述具体活动，不销售人的所有权。
- 价格与可预约日：时薪最多两位小数；最低时长为整数 1–8 小时；可预约日使用 `周一` 至 `周日` 的数组，至少一个、不重复。
- 日期和时间：按照 `Australia/Melbourne` 的当地时间，预约今天起 60 天内的日期；开始时间为 09:00–22:00，结束须在当天午夜前。今日已过的开始时间和未开放的星期不可预约。
- 预约时长和留言：整数小时，满足服务者最低时长，最长 8 小时；留言 1–300 字。提交前说明活动、费用和边界。
- 暂停展示：`active: false` 的资料不出现在发现列表，也不接受新预约。原型中的取消不会扣款或退款。

## 下一阶段：让真实用户共同使用

1. 账号、数据库和对象存储：保存资料、活动、可预约时段与订单；为用户资料与操作配置权限。照片处理和实名资料分开，身份文件不放入公开资料。
2. 真实供需流程：服务者收到申请并接受或拒绝，消息围绕订单发送；服务者可以修改展示和可预约时段，历史订单保留预约时的价格快照。
3. 支付与结算：后端以整数分锁定时薪、平台费、时长和金额，支付平台 webhook 验证结果；根据完成、退款和争议状态安排结算。客户端显示与本机状态不能确认支付成功或服务完成。
4. 履约与支持：取消退款规则、举报拉黑、客服和后台管理；真实成交评价仅开放给符合条件的完成订单。并发预约、超时占位和防止重复支付必须由后端处理。
5. 小范围试运营：先验证墨尔本的供给和复购，再决定原生 App 与其他城市扩展。真实收费前确认维州适用规则、支付平台要求、服务者安排及退款责任。

## 订单状态

推荐主流程：`待对方确认 → 已接受 → 待支付 → 已预约 → 服务进行中 → 待完成确认 → 已完成 → 已结算`。免费活动跳过支付及结算。

`已拒绝`、`已取消`、`已过期` 是未履约分支；发生付款后取消时，通过 `退款处理中 → 已退款` 保留退款记录；`争议处理中` 暂停结算，由客服处理后返回明确状态。只有满足规则的已完成付费订单才可结算平台费。双方确认、实际退款和结算都属于后端功能，原型状态不能代表真实交易。

## 纯业务函数接口

`src/marketplace.js` 导出下列接口：

- `PLATFORM_FEE_BPS = 1500`。
- `bookingBreakdown(rate, hours, minHours = 1, feeBps = PLATFORM_FEE_BPS)` 返回澳元数字 `{ total, platformFee, providerEarnings }`；使用整数分计算，允许零时薪，参数错误抛出中文错误。
- `filterProfiles(items, { query = '', service = '全部', area = '全部区域', gender = '不限', maxRate = 200, sort = '推荐' } = {})` 返回筛选后的新数组。推荐保留原顺序；价格排序为 `价格从低到高` 或 `价格从高到低`。
- `MelbourneDate(offset = 0)` 返回墨尔本当地日期字符串 `YYYY-MM-DD`，按整数天偏移。
- `validateProfile(profile)` 与 `validateReservation(profile, { date, time, hours, message })` 返回首个中文校验错误；通过时返回空字符串。
