# 手机原型体验指南

这一版是可以点击、填写、发布、预约和聊天的网页 App。展示照片为真人摄影素材，预置人物、经历、价格与需求都是虚构示例，不代表照片人物真实入驻。数据只保存在当前浏览器，所有收付款均为演示。

## 打开方式

手机建议使用已经发布的网页地址，在 Safari 或 Chrome 打开。iPhone 可通过分享菜单“添加到主屏幕”；Android 支持的浏览器可用“安装应用／添加到主屏幕”。HTTPS 网页提供完整的主屏幕与离线支持，当前不是应用商店安装包。

也提供单文件 `demo.html` 用于下载预览。文件内包含完整交互与展示照片，不依赖外部资源；部分手机文件预览器不会执行 JavaScript，遇到这种情况请打开网页版本。开发者可执行 `npm run export` 重新生成单文件。

## 路线一：预约职业 Coffee Chat

1. 发现 → 职业交流 → 金融行业 Coffee Chat。
2. 点“预约这项服务”，选择 30 或 60 分钟，查看 A$100／A$180 总价。
3. 填写日期、时间和想聊的问题，勾选成年及演示说明，提交。
4. 进入消息会话，发送留言；需要体验另一方回应时主动点“生成演示回复”。
5. 依次点“演示对方接受”→“模拟付款”→“演示服务完成”。这些按钮只模拟状态，不扣款。
6. 完成后写评价或再约一次；刷新页面，记录仍在当前浏览器。

## 路线二：发预算，请别人帮忙

1. 发布 → 发布需求，填写昵称、目标、预算、日期和预计时长。
2. 发布后进入自己的需求详情，点“生成演示申请”。
3. 查看申请说明并选择一位帮忙的人，进入订单消息会话。
4. 确认内容后模拟付款和完成，查看订单总价与 15% 佣金试算。

你也可以在需求广场申请一条示例需求，在消息里主动模拟发布者选中你，体验作为服务者接单的流程。

## 路线三：挂出自己的服务

1. 发布 → 提供服务，填写展示名、经历、服务内容与价格。
2. 职业服务使用固定时长套餐，活动陪伴使用时薪；可以继续挂出多项服务。
3. 我的 → 查看自己的服务，点进详情，可以暂停服务或生成演示预约。
4. 接受演示预约，模拟客户付款和服务完成，返回“我的”查看模拟到手金额。

买方花费不会计入你的收入；只有完成的演示接单进入服务者收入试算，仍没有真实余额。

## 其他入口

兴趣搭子可发布免费活动、申请、取消；经验分享可发文字内容；个人展示支持本机照片与介绍；核验中心展示未来真人、身份和职业核验的流程说明，当前不收集证件，也不显示虚假的核验结果。

这轮先看板块是否好找、价格是否清楚、发布是否顺畅、消息和订单是否好理解。不同手机、账号之间的数据尚不共享。
